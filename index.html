LLM Reasoning & Agentic Systems

Self-Correcting RAG with Continual Faithfulness Monitoring

Hybrid retrieval + fine-tuned reranker + claim-level faithfulness scoring that catches its own hallucinations before they reach the user.

Details

Built a RAG system that decomposes its own generated answers into individual factual claims and checks each one against the retrieved context with an NLI cross-encoder — catching confident-sounding hallucinations rather than trusting fluent output. Hybrid BM25 + dense retrieval with reciprocal rank fusion over LangChain's documentation corpus, upgraded with a cross-encoder reranker fine-tuned on synthetically-generated queries and hard negatives mined from the retriever's own mistakes. Shadow-eval confirmed the reranker improved recall@k from 0.75 to 0.875 and fixed two previously undiscoverable documents.

Quiet-STaR - Entropy-Gated Self-Taught Reasoning

Entropy-gated reasoning: ~12x lower loss at ~50x less compute than dense token-by-token rationales.

Details

Reimplemented Quiet-STaR (Zelikman et al., Stanford 2024) on GPT-2 / TinyStories, where the model learns to generate internal rationales token-by-token before predicting the next word. Designed an entropy-gated mechanism that triggers rationale generation only at high-uncertainty tokens, rather than at every token as in the original paper - concentrating compute where reasoning actually helps.

LoopFix - Adversarial Multi-Agent Coding System

Builder vs Breaker agents debate code correctness — 75% solve rate, fully offline on one GPU.

Details

Built a multi-agent debate system where a Builder agent writes Python solutions and a Breaker agent attacks them with adversarial test cases - explaining why each one could break the code. They iterate until the solution is bulletproof or hits the round limit. Two-temperature architecture: Builder at 0.2 for deterministic correctness, Breaker at 0.8 for creative adversarial reasoning. Benchmark: 75% of problems fully solved (6/8), avg. 1.8 rounds to solve, zero API costs.
